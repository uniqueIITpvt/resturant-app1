# Unique Café Frontend Documentation

## Event Offers - Admin Guidelines

### Banner Image Requirements

When creating or editing event offers, follow these guidelines for optimal banner images:

#### Technical Requirements

- **Dimensions:** 1200 × 600 pixels (2:1 ratio)
- **Orientation:** Landscape mode is strongly recommended
- **Resolution:** 72-150 DPI
- **File Size:** Maximum 2MB
- **File Formats:** JPG, PNG, or WebP (WebP preferred for better quality-to-size ratio)
- **Color Space:** RGB

#### Design Best Practices

1. **Composition:**
   - Ensure the main subject is clearly visible and centered
   - Allow for some space around the edges (safe zone)
   - Consider that on mobile devices, the image will be viewed at a smaller size

2. **Text on Images:**
   - Use minimal text on the image itself
   - Ensure high contrast between text and background
   - Use larger fonts (avoid small text that becomes unreadable on mobile)
   - The component already displays the offer name, description, and details, so keep image text minimal

3. **Visual Appeal:**
   - Use high-quality, professional images
   - Ensure proper lighting and clear focus
   - Use images that convey the mood or theme of the offer
   - Food imagery should be appetizing and professionally photographed

4. **Branding:**
   - Follow brand color guidelines
   - Include logo only if it doesn't distract from the main offer
   - Maintain consistent visual style across all event offers

#### Platform-Specific Display

The event offers component displays images differently across devices:

- **Desktop:** Images are displayed at approximately 600px width in a side-by-side layout
- **Tablet:** Images maintain aspect ratio but are scaled down
- **Mobile:** Images are displayed at full width (approximately 350-400px) above the content

#### Testing

Before publishing an event offer:
1. Preview how it looks on multiple devices
2. Check loading speed (compress images if necessary)
3. Ensure text on the image is readable at all sizes

#### Examples

Good banner image examples:
- Clean, simple food photography with ample negative space
- Seasonal themes with subtle, relevant decorative elements
- Promotional text that is large, centered, and high-contrast

Images to avoid:
- Blurry or pixelated images
- Overly busy compositions with too many elements
- Text that is too small or low-contrast
- Images with irrelevant content

By following these guidelines, you'll ensure that event offers display optimally across all devices and provide an engaging user experience.
